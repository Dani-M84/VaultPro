# VaultPro Android - Auto Build

Cada vez que haces push a main, GitHub compila el APK automaticamente.

### Como modificar:
1. Edita main.py directamente en GitHub (lapiz)
2. Commit changes
3. Ve a Actions > ultimo workflow > descarga el APK en Artifacts

### Como descargar APK:
Actions tab > click en el ultimo build > Artifacts > VaultPro-APK.zip
